# スタイリング

- **見た目に関わる値（色・余白・サイズ・角丸・タイポグラフィなど）は、すべて theme に名前付き定数として置く。** 置き場所は `src/theme.ts` か `src/theme/` 配下（どちらを使うかはリポジトリによる）。コンポーネントのファイルにマジックナンバーや hex / rgba の直書きを置かない
- **theme の外に「そのファイル専用の色定数」を作らない。** 同じ値が複数ファイルに散る原因になる（過去に `WHITE_ALPHA_60` が2ファイルに重複していた実績がある）
- 新しい定数を足す前に、同じ値をカバーする既存の定数が無いか確認する
- ライト / ダークで変わる値は各テーマのオブジェクトへ、明暗に依らず固定の値（色付きの面に載せる文字、シート背後の幕など）は固定色のオブジェクトへ置く
- **既存の色を変えずに定数へ切り出すときは、値が変わっていないことを確認する。** 表記ゆれ（`0.5` と `0.50`、`#000` と `#000000`）は同じ定数へ寄せてよい
