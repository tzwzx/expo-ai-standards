# Baseline rules for code changes

> 📌 Unless explicitly instructed otherwise, a code change must not affect any of the following:

- Design (appearance, layout, colors, fonts, etc.)
- Styling (CSS, `style` props)
- UI (user interface, component arrangement)
- Existing behavior (logic)

Keep every change scoped to what was asked; do not touch anything else.
